## 🧭 About me

I'm a computer science student, problem solver, and aspiring entrepreneur. I build software to **save people time, make complex tasks easier, and help them make better decisions**.

My work spans full-stack applications, automation, data systems, collaborative tools, and AI. I start with the people using a product: what slows them down, what they need, and how a solution can fit into their everyday lives. That understanding guides my choice of technology.

I'm driven by a long-term ambition to build a technology company that delivers useful, dependable products. For me, progress means taking an idea through research, implementation, feedback, and continuous improvement.

## 🚀 Projects with a purpose

### ⚡ Demo Automation Platform

![Automation](https://img.shields.io/badge/AUTOMATION-2563EB?style=flat-square) ![Voice Workflows](https://img.shields.io/badge/VOICE_WORKFLOWS-7C3AED?style=flat-square) ![Full Stack](https://img.shields.io/badge/FULL_STACK-0891B2?style=flat-square)
**Making product demos easier to prepare and personalize.**

I'm working on a platform that streamlines the path from understanding a prospect's needs to preparing a tailored product demo. It brings together clarification workflows, uploaded knowledge sources, voice interactions, and demo previews to reduce repetitive preparation work for sales and product teams.

My work includes backend workflows, multi-file knowledge handling, frontend integration, and latency improvements through shared database connections and reusable workflow components.

**Built with:** TypeScript · TanStack Start · Python · FastAPI · PostgreSQL · Supabase · LangGraph · Voice integrations

### 🌱 Knovera — Personalized Learning
**Helping children learn with curiosity and supporting families along the way.**

My final-year project explores personalized learning for children aged 4–14. It brings together learning activities, progress signals, and parent insights, with an emphasis on productive struggle, age-appropriate support, and thoughtful handling of children's data.

**Focus:** learning experience · personalization · parent dashboard · consent and privacy

### 💻 Code Sync — Collaborative Coding
**Making it easier to code and communicate together.**

A real-time code editor project combining shared coding rooms, collaboration, chat, and an AI assistant. It explores how a single workspace can help people discuss ideas and work through problems together.

**Built with:** React · Node.js · Express · MongoDB

### 🏋️ Gym Management & Member Retention — In Development
**Helping gym owners understand attendance and stay connected with members.**

I'm developing an application around member attendance, visit frequency, capacity, and trainer assignments. The goal is to give gym owners a clearer view of their operations and help them identify members who may need support or encouragement to return.

**Focus:** usable dashboards · QR-based check-ins · member engagement · daily operations

### 🌍 [AQI Predictor — Air Quality Forecasting for Pakistan](https://github.com/sajjadgill720/AQI-PREDICTOR)
**Making air quality forecasts easier to access and understand.**

An end-to-end forecasting project connecting air quality data, feature engineering, scheduled model training, and an interactive dashboard for Pakistani cities.

**Focus:** data pipelines · forecasting · model evaluation · accessible visualization

### 🧪 AutoML System
**Reducing repetitive work in machine learning experiments.**

A modular system for tabular data that handles preprocessing, model training, evaluation, selection, and hyperparameter tuning. It helps make experimentation more organized and repeatable.

**Built with:** Python · scikit-learn · modular data pipelines

### 📊 AI Boom vs. Dot-Com Bubble — Data Visualization
**Using data to examine the relationship between market excitement and fundamentals.**

A comparative visualization project exploring technology market cycles. My contribution focused on valuation metrics and P/E analysis, turning financial data into explanations that people can inspect and discuss.

**Focus:** analytical thinking · financial data · visual storytelling

## 🎯 How I approach a problem

- **Understand the people:** learn who faces the problem and what a useful outcome looks like.
- **Break it down:** turn complexity into manageable decisions and clear implementation steps.
- **Own the solution:** connect the interface, backend, data, and user experience.
- **Validate and improve:** use testing, measurements, and feedback to refine the result.
- **Stay focused:** follow through, document the work, and keep learning.
